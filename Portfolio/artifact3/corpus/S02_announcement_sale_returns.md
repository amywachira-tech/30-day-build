# #policy-updates

<!-- access: agent -->
**Posted by Finance Operations, Feb 2, 2026**

Policy change: sale item returns

Effective Tuesday, February 3, 2026, sale items can be returned within **30 days** of delivery. The previous window for sale items was 60 days.

Standard (full-price) items are unchanged and remain returnable within 60 days of delivery.

The window is based on the delivery date, not the order date. Orders delivered before February 3 keep the old 60-day window.

Please apply this from tomorrow's first shift. Questions to Finance Operations.

# Returns FAQ

<!-- access: agent -->
## How long does a customer have to return an item?

All items, including sale items, can be returned within 60 days of delivery. The 60 days start on the delivery date shown in the order history, not the order date.

<!-- access: agent -->
## What condition does the item need to be in?

Items should be unused and in their original packaging where possible. Furniture that has been assembled can still be returned if it is undamaged, but the customer must disassemble it before collection.

<!-- access: agent -->
## How does the customer start a return?

The customer starts the return from their order history on the Kestrel website. A prepaid return label is emailed to them. For large furniture, a collection is booked instead of a label.

<!-- access: agent -->
## Who pays for return shipping?

Kestrel pays for return shipping on all returns within the return window.
